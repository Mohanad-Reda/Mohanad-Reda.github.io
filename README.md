# Mohanad Reda — Portfolio

Personal portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Deploy

1. Create a public repository named `Mohanad-Reda.github.io` (recommended) or `portfolio`.
2. Put everything in this folder at the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save. GitHub will publish the site.

If the repository is named `Mohanad-Reda.github.io`, the site will be available at:

`https://Mohanad-Reda.github.io/`
