01 / ML · COMPUTER VISION

Dinosaur Skull
Fossil Classifier

A six-class image classifier built around a problem that didn't have a convenient ready-made dataset. I manually collected fossil skull images, built a cleaning and augmentation pipeline, then compared ResNet50, a fine-tuned ResNet50, and ConvNeXtV2.

The interesting part wasn't just training a network — it was dealing with the data problem first.

Python PyTorch ResNet50 ConvNeXtV2 Scikit-learn

02 / DEEP LEARNING

Plant Disease
Detection

A comparative deep-learning study on the PlantVillage dataset: a baseline CNN, MobileNetV2 transfer learning, and an attention-based CNN. MobileNetV2 produced the strongest results, and I wrapped the final workflow in a Gradio interface for image predictions.

92.7% accuracy
92.1% precision
90.5% F1 score
Python TensorFlow MobileNetV2 Gradio
